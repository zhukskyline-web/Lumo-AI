# Lumo AI — Telegram-бот + Mini App

ИИ-ассистент с токенами, тарифами и оплатой в Telegram Stars. Хостинг: Render (Free).

## Запуск за 10 минут

1. **Бот.** В @BotFather: `/newbot` → получи `BOT_TOKEN`. Для Stars ничего подключать не нужно.
2. **ИИ бесплатно.** Зарегистрируйся на console.groq.com → создай API key → это `AI_API_KEY`.
3. **GitHub.** Залей папку проекта в новый репозиторий.
4. **Render.** New → Blueprint → выбери репозиторий (подхватится `render.yaml`). Впиши `BOT_TOKEN` и `AI_API_KEY`.
5. Когда сервис запустится, открой бота, нажми `/start` → «Открыть Lumo».
   Если кнопка не открывает приложение, добавь переменную `BASE_URL` = адрес сервиса (https://….onrender.com).

## Тарифы и токены
Настраиваются в `main.py` (`FREE_DAILY`, `PLANS`). Free: 10 000 токенов в сутки. Plus/Pro/Max: 150/400/900 ⭐ за 30 дней.
Токены списываются по реальному usage от модели. Другая модель/провайдер: меняй `AI_BASE_URL` и `AI_MODEL` (любой OpenAI-совместимый API).

## Важно про бесплатный Render
- Сервис засыпает без трафика; в коде есть самопинг каждые 10 минут, пока он бодрствует. Для надёжности добавь пинг `/health` на UptimeRobot (бесплатно).
- **Диск временный:** SQLite стирается при каждом деплое/перезапуске, а значит, баланс и подписки пропадут. Для реальных платежей перенеси базу во внешнюю (Supabase, Neon, Turso: у всех есть бесплатный тариф).
- Возвраты Stars: `charge_id` хранится в таблице `payments` (метод `bot.refund_star_payment`).
